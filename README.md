# SQL Sales Data Analysis

## Project Overview

This project was completed as part of an SQL internship exercise using SQL Server. The goal was to explore, clean, and analyze a sales dataset to generate meaningful business insights.

## Objectives

* Explore and understand the dataset.
* Clean and validate data.
* Identify duplicate records.
* Analyze sales performance and revenue trends.
* Evaluate product and customer performance.
* Examine referral sources, payment methods, and shipping locations.

## SQL Skills Applied

* SELECT, WHERE, ORDER BY, GROUP BY
* COUNT, SUM, AVG
* CTEs and Window Functions
* CAST and TRY_CAST
* Data Cleaning and Validation

## Analysis Performed

* Data exploration and cleaning
* Duplicate detection
* Product performance analysis
* Customer behavior analysis
* Revenue and sales trend analysis
* Referral source and payment method analysis
* Shipping address analysis

## Key Insights

* Identified top-performing products.
* Measured product contribution to revenue.
* Analyzed customer purchasing behavior.
* Evaluated referral source effectiveness.
* Examined payment and shipping trends.

## Tools Used

* SQL Server
* SQL Server Management Studio (SSMS)
